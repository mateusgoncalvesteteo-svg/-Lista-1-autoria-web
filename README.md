## 📌 Lista de Exercícios (Texto Completo)

1. **Alteração de Cor de Texto:** Crie um formulário simples com 4 botões e um parágrafo que, ao clicar em cada um, altere o texto do parágrafo para vermelho, verde, azul e amarelo, respectivamente.
2. **Alteração de Plano de Fundo com Hover:** Crie uma página com 4 links, cada um representando o nome de uma cor, que, utilizando o evento `onmouseover`, altere a cor do plano de fundo para a cor correspondente (dica: utilize o atributo `style="background-color: red;"`).
3. *(Observação: A numeração da lista original pula da questão 2 para a 4)*
4. **Ocultar/Mostrar Parágrafo:** Crie uma página que possua um parágrafo e um botão "Ocultar/Mostrar". Ao clicar no botão, o parágrafo é ocultado (caso esteja sendo mostrado) ou exibido (caso esteja oculto).
5. **Validação de Cadastro:** Crie um formulário com os campos para cadastrar o usuário de um sistema (login, senha e confirmar senha). Valide se todos os campos estiverem preenchidos, se os campos senha e confirma senha forem iguais e a senha possuir entre 6 e 10 caracteres. Envie um alerta (`alert`) com a resposta.
6. **Verificador de Palíndromo:** Fazer uma função para identificar se a palavra digitada no `input type=text` pelo usuário é um palíndromo ou não. Uma palavra é denominada um palíndromo se for invertida e a leitura dela permanecer sem nenhuma alteração. Ex.: aba, radar, reter, rever, rir. Após criada, chame a função usando eventos.
7. **Inversão de Nomes:** Crie um código em JavaScript que receba os nomes de 5 pessoas através de campos de formulário. Ao clicar em um botão *Inverter*, armazene-os em um array e apresente os valores nos mesmos campos do formulário, porém na ordem inversa da que foram inicialmente digitados.
8. **Validador de CPF:** Crie um formulário de cadastro de CPF cliente. Crie uma função para verificar se o CPF é válido. Crie um parágrafo para informar se o CPF é válido ou inválido.
9. **Intercalador de Palavras:** Crie uma função em JavaScript que receba 2 palavras através de campos de formulário e depois imprima-as intercaladas em um outro campo de formulário que deve estar desabilitado (o usuário não deve conseguir digitar nenhum valor nesse campo). Ex.: 'Joao' e 'Mary'; a impressão deve ser: 'JMoaaroy'.
10. **Estatísticas Numéricas:** Escreva um script que receba três números fornecidos pelo usuário através de um formulário e exiba os números digitados em forma de tabela, acompanhados da soma, média, produto, maior e menor número.
11. **Tabuada de Multiplicação:** Escreva um script que receba um número fornecido pelo usuário através de um formulário e exiba em forma de tabela a sua tabuada de multiplicação.
12. **Buscador de Palavras em Texto:** Crie uma página contendo um determinado texto. Acima do texto, inclua um formulário com um campo e um botão *Pesquisar*. Ao digitar uma palavra e pressionar o botão, conte quantas ocorrências daquela palavra existem no texto e destaque cada ocorrência com plano de fundo amarelo. Caso a palavra não exista, exiba uma mensagem informando que a busca não retornou nenhum resultado.
13. **Data por Extenso:** Faça um script que receba uma data no formato "dd/mm/aaaa" e escreva a data por extenso usando a função `split` para quebrar a string. Exemplo: Para a entrada "06/09/2024" deve ser escrito "06 de setembro de 2024".
